# Compatibility and measured environment

Checked 2026-11-04 in `datpt_lifemate`: Python 3.11.18. The model packages were initially absent, then installed for the real-model runs. Default sandbox `nvidia-smi` and Hugging Face DNS checks failed, but elevated local execution worked. Physical GPU 2 is an NVIDIA RTX A5000 with 24 GB total memory. Disk available in the project filesystem was about 1.5 TB at the latest check. Both baseline checkpoints are present locally.

The [Qwen3-ASR-0.6B card](https://huggingface.co/Qwen/Qwen3-ASR-0.6B) documents Vietnamese support, Apache 2.0, local download, and the `Qwen3ASRModel.from_pretrained(...).transcribe(audio=..., language=...)` API. The [Qwen3-4B-Instruct-2507 card](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) documents Apache 2.0 and 4.0B parameters. Hugging Face API metadata identified revisions `5eb144179a02acc5e5ba31e748d22b0cf3e303b0` (ASR; created 2026-01-28) and `cdbee75f17c01a7cc42f958dc650907174af0554` (LLM; created 2025-08-05), both Apache 2.0. Model weight sizes are 1,876,091,704 and 8,044,982,000 bytes respectively; the exact on-disk tensor counts will be recorded after download. The model card figures are not a complete architecture audit.

PydanticAI was unavailable in the requested Conda environment at implementation time, so the runner uses a small OpenAI-compatible tool loop. It requires a loopback endpoint and performs official ToolEnv validation and sequential execution. Qwen ASR and the vLLM `hermes` tool parser ran on GPU 2. The 20-sample TRAIN run had 0 runtime failures and a 10.177-second maximum per-sample time on this A5000; the organizer's A30 budget remains unverified. The baseline safetensors stored-tensor counts total 4,960,476,672 parameters, but complete loaded-architecture auditing remains pending. Remaining model licenses, release dates, weight revisions, exact parameter totals, and legal pairings are pending.
